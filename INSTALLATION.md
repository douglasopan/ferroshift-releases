# Installation

1. Get the approved launcher for **Windows x64** or **Linux x86_64** from its versioned Release or the [official download page](https://ferroshift.online/play).
2. Follow the instructions supplied with that platform's installer. Keep the existing game installation and saves when updating.
3. Create or sign in to your FERROSHIFT account and verify your email address. Internet is needed for sign-in, first activation and updates.
4. Start with 33 free campaign puzzles. The optional full license adds 39 campaign challenges.

The launcher verifies the expected SHA-256, package size and installation layout. It installs into a temporary location before replacing the current game and retains the recovery behavior of the supported launcher. A failed integrity check must not install the downloaded file.

Downloads are pinned to a specific release and file. The launcher does not use an unversioned `latest` download URL. If a version needs to be withdrawn, the official catalogue can point eligible clients to a retained, approved version.

Operating system warnings depend on the signing status of the particular installer. Check the release notes and publisher details. These instructions do not require disabling system protections.

For current platform requirements and troubleshooting, use the [official website](https://ferroshift.online/play) or [contact the team](mailto:ferroshift@thepan.art).

# Instalação

Baixe o launcher aprovado para seu sistema, entre em uma conta com e-mail verificado e siga as instruções da versão. Ao atualizar, mantenha a instalação e os saves existentes. O launcher confere o tamanho e o SHA-256 antes de instalar. O acesso grátis inclui 33 puzzles; a licença completa é opcional e adiciona 39 desafios.
