# FERROSHIFT

![FERROSHIFT factory](https://thepan.art/games/ferroshift/factory-preview.png)

**Can you solve every puzzle?**

Build, connect and improve a working factory. Turn raw minerals into finished products, manage heat and find a more efficient solution to each contract.

Start for free with **33 campaign puzzles**. The optional full FERROSHIFT license adds **39 campaign challenges**. A FERROSHIFT account with a verified email address is required to activate access.

[Start for free](https://ferroshift.online/play) · [Official website](https://ferroshift.online/) · [Development updates](https://ferroshift.online/devlog?lang=en)

## Downloads

This is the public distribution repository for approved Windows and Linux releases. Versioned installers and game packages will appear in [Releases](https://github.com/douglasopan/ferroshift-releases/releases). During the transition, get the current installers from the [official download page](https://ferroshift.online/play).

Use the launcher for your operating system. It checks account access, downloads the game and verifies the package's SHA-256 and size before installation. Downloading a package does not grant the optional full game license. Sign-in, first activation and updates need internet access.

The source code of the game is maintained separately. It is not published in this repository. This repository does not distribute private test APKs, debug builds, accounts or saves.

See [installation instructions](INSTALLATION.md), [release history](CHANGELOG.md) and the [proprietary notice](PROPRIETARY-NOTICE.md).

**Será que você é capaz de resolver todos os puzzles?**

Comece grátis com **33 puzzles da campanha**. A licença completa é opcional e adiciona **39 desafios**. Para ativar o acesso, é necessária uma conta FERROSHIFT com e-mail verificado.

Este repositório distribui versões aprovadas para Windows e Linux. Os arquivos de cada versão ficam em **Releases**; durante a transição, os instaladores atuais estão na [página oficial](https://ferroshift.online/play).
