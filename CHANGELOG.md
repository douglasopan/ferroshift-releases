# Release history

## Distribution transition

Preparation of a separate public repository for FERROSHIFT Windows and Linux installers and game packages. Source code remains in the private development repository.

Only approved binaries are attached to Releases. Each published version records its exact filename, byte size, SHA-256 and existing signing status. Release notes will identify the game version and platform; they do not substitute for device QA or change account access.

Current approved releases remain listed on the [official download page](https://ferroshift.online/play) until their migration is verified.
